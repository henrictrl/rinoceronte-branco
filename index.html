Arraste as formas livremente • Duplo clique centraliza
A resolução aqui está reduzida. O site é apenas um ambiente de testes para criativos. As composições serão finalizadas manualmente depois.

Como usar o Estúdio

1. Escolha a Arte Base

Selecione uma das variações numéricas na lateral. Temos opções de contorno, preenchidas e vazadas preparadas para reagirem perfeitamente às cores.

2. Molde a Geometria

Crie formas sólidas clássicas ou polígonos orgânicos irregulares. Deslize a barra de "Lados" para transformar a forma em tempo real sem perder a característica original.

3. Ajuste as Cores

Mude as cores livremente com os controles deslizantes HSL ou digitando códigos HEX diretamente nas caixas de texto para obter tons exatos.

4. Trave suas Escolhas

Gostou de uma cor ou forma geométrica? Clique no ícone de cadeado para protegê-la. Assim, ao sortear tudo, suas escolhas favoritas serão mantidas.

5. Posicione e Exporte

Arraste a forma geométrica diretamente com o mouse ou dedo para criar composições descentralizadas. Quando finalizar seus testes, baixe um PNG para referência.
